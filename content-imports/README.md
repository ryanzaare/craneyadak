# فایل‌های ورود محصول

هر فایل JSON یک «دسته» از محصولات است که از پنل وردپرس وارد می‌شود:

**محصولات ← ورود محصولات از فایل**

## گردش کار

1. نام محصولات (و در صورت وجود، صفحه‌ی کاتالوگ) را می‌دهید
2. فایل JSON آماده و اعتبارسنجی می‌شود
3. فایل را در پنل آپلود می‌کنید
4. محصولات به‌صورت **پیش‌نویس** ساخته می‌شوند
5. کارشناس فنی هر `[نیازمند بررسی فنی]` را با داده‌ی واقعی پر می‌کند
6. پس از تایید، دستی منتشر می‌شوند

افزونه برای افزودن محصول جدید **هرگز** تغییر نمی‌کند.

## اعتبارسنجی پیش از تحویل

```bash
node content-imports/validate.mjs content-imports/batch-01.json
```

بررسی می‌کند: اسلاگ لاتین، وجود دسته و برند در تاکسونومی، بخش‌های الزامی،
طول متن، اعداد مهندسی بدون پشتوانه، کد قطعه‌ی ناشناخته، لحن ماشینی، و طول
توضیح متا. کد خروج ۱ یعنی فایل نباید تحویل شود.

## فیلدها

الزامی: `title`, `slug` (لاتین), `excerpt`, `content`
اختیاری: `category`, `brand`, `sku`, `buy_mode`, `stock_status`, `price`,
`specs[]`, `oem[]`, `models[]`

ساختار کامل در صفحه‌ی «ورود محصولات از فایل» نمایش داده می‌شود.
